# Manifeste pour l'avenir des peuples

Lettre ouverte de **Emmanuel Edel** à Donald J. Trump, publiée en français et en anglais.

## Lire les deux versions
- [English manifesto](index.html)
- [Manifeste français](fr.html)

Le site est indépendant des entreprises E-CAB et EDDJI. Les opinions exprimées sont celles de l'auteur.

## Mise en ligne GitHub Pages
1. Ouvrir **Settings > Pages** dans ce dépôt.
2. Dans **Build and deployment > Source**, choisir **GitHub Actions**.
3. Enregistrer si nécessaire.
4. Aller dans **Actions > Publish Manifesto on GitHub Pages**, puis **Run workflow** si aucun nouveau lancement ne démarre.

Adresse publique après publication : https://emmanuel67140.github.io/manifeste-avenir-des-peuples/

Le workflow fabrique automatiquement les PDF à partir des pages HTML, puis publie l'ensemble du site.
